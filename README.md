# Luis Revilla

**Automation Engineer · Power Platform & Full-Stack Developer** · Chicago area

I build the automation platforms and internal tools that businesses run on. I moved from operations into IT by automating my own job, and now I design RPA and workflow systems on Power Automate, Dataverse and SQL Server, with React/TypeScript apps on top. U.S. Army veteran.

**Currently:** building an enterprise RPA platform for a material-handling company. It has a central job queue, dispatch to unattended VMs, retries, dead-letter handling and audit logging, with end-to-end automation of a legacy ERP.

### Impact

- **~6 hrs → ~20 min** per return transaction (94% faster)
- **~250K ERP records** across 8 datasets, unified in one tool used by **~20 people in 4 departments**
- A modular VBA application of **~2,400 lines in 17 modules**, with pluggable transaction handlers
